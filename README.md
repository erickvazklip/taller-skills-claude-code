## Cambiar la fuente de descarga a Google Drive

Todos los archivos viven en `descargas/`. Para servirlos desde Drive, pega el ID de cada archivo en el campo `drive` de `assets/materiales.js`. El archivo en Drive debe estar compartido como *Cualquier persona con el enlace*. Si `drive` está vacío, el botón descarga la copia de `descargas/`.
